# BoardHub / OpenBoard Engine

遊ぶ、試す、AIとルールを育てるボードゲーム・プラットフォームのプロトタイプ。
TypeScript の純粋なゲームエンジンと、React / Vinext / Cloudflare Workers / D1 による Web アプリです。

## 開発プラットフォームとしての方針

個人作家が通信や保存を作り直さず、ルールとUIに集中し、第三者の試遊から作品を改良できる環境を目指します。
最初の到達点は「運営以外の作者が、運営によるコード修正なしで公開し、試遊を受けて改善版を公開できること」です。

- [戦略・90日計画・成功指標](docs/platform-strategy.md)
- [開発・広報の実行バックログと完了条件](docs/platform-roadmap.md)
- [初期作者向け広報文案・観察シート](docs/creator-outreach.md)
- [作者向け制作ガイド](https://board-hub.babachan.workers.dev/studio/guide)

ブラウザ内の設定制作は連結ゲームが対象です。本命はルールとUIをコードで派生開発できる基盤で、[コード対応の設計と実装順](docs/code-platform.md)に記録しています。レビュー保存も引き続き実装対象です。

## コードで派生ゲームをつくる（ローカル実証版）

`/studio/code` から島の工房のコード制作キットをZIPでダウンロードできます。本体のアカウントやDBを含まず、ルール・開発用UI・CPU・テスト・共通SDK・ローカルホストだけを切り出します。

```sh
pnpm kit:export ./outputs/my-isleworks
cd outputs/my-isleworks
npm test
npm start
```

Node 24以降、追加依存のインストール不要。別ブラウザで同じローカルURLを開くと別席で試遊できます。`AI_REQUEST.md` を外部AIに渡し、ゲーム側だけを変更できます。フォルダだけをゲーム用GitHubリポジトリに保存すれば、そのゲーム単位でフォークできます。

現段階ではローカル実行のみです。アップロードコードの隔離実行、GitHub接続からの自動配信、BoardHub本番への公開は未実装です。

## 遊べるゲーム

- 島の工房：2個のダイス、初期配置、資源交渉、最長路、発展カードを扱う2〜4人の開拓ゲーム。
- 綴りの王国：10種類の行動カード、連続使用、購入、廃棄、攻撃・防衛を備える2〜4人のデッキ構築。
- 街道と城郭：独自構成72タイル、回転配置、城郭・街道・修道院・農地、占有と多数決の2〜4人ゲーム。
- カラハ、リバーシ、四目並べ、3つの短時間ミニゲーム。

CPU練習、友だちへの招待、チュートリアル、詳しいルール、効果音、盤面アニメーションを備えます。
既存商業ゲームの名称・画像・説明文・ソースコードは収録せず、独自名称・描画・文章を使用しています。

## 作る・公開する

「ゲームを探す」に収録ゲーム・全公開作品・お気に入りを集約。開発は「プロジェクト」、アカウントとレビューは「マイページ」に分かれています。

`/studio` で連結ゲームのテンプレートを自分の作品としてD1に保存。
AIへの指示から変更案を作り、ブランチで差分と試遊を確認してmainへ反映します。
AI API未設定時も「ChatGPT用の依頼をコピー」とJSON取り込みを利用できます。
公開作品は `/community` へ。ホーム掲載は管理者だけが選びます。

Googleログインに対応します。お気に入りと作品をアカウントで引き継ぎ、ゲストの作品もログイン時に移管します。
接続設定は [GOOGLE_LOGIN.md](GOOGLE_LOGIN.md)。未設定時はゲスト利用できる状態を維持します。
ログインしていない場合、ブラウザの秘密キーで作品の所有を識別します。Cookieを失う前にGoogleでログインしてください。
レビューは現時点では端末内の記録です。

## 開発

Node 24、package.jsonで指定したpnpmを使用します。

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm exec wrangler d1 migrations apply DB --local
pnpm dev
pnpm build
```

デプロイ手順は [DEPLOY.md](DEPLOY.md)。Cloudflare Workers BuildsでGitHub mainを接続すると、pushから自動公開できます。

## 構成

| ディレクトリ | 役割 |
|---|---|
| `engine/` | 状態・アクション・手番・検証・リプレイの共通契約 |
| `games/` | 各ゲームの純粋なルールとCPU |
| `server/` | D1永続化、参加トークン検証、競合制御、非公開情報の投影 |
| `app/`, `components/` | カタログ、ゲーム、ルール、作家ワークスペース |
| `drizzle/` | 追記型D1マイグレーション |
| `worker/` | Cloudflare単体のエントリーポイント |

対戦はサーバーを正としてrevisionで競合を防ぎ、同じ操作IDの再送を二重処理しません。
山札順・他人の手札・生のイベント履歴は非公開ゲームのAPIに返しません。
通信は約1.5秒間隔のポーリング。マッチング、Elo、課金、任意生成コードの実行は未実装です。
