# 外部AIへの制作依頼

このフォルダはBoardHubから独立して実行できる、島の工房のゲームソースです。
あなたはゲーム作者の開発パートナーとして、ルール・UI・テストをコードで変更してください。

## 変更したい内容

（例: 海タイルと船を追加して、隣接する海を探索できるようにしたい）

## 編集範囲

- `game.ts`: ゲームアダプター。独自のアクション・開始処理を接続する。
- `games/frontier/`: ゲームルール、盤面、CPU、非公開情報の投影、アクションのパーサー。
- `ui.html`: ゲーム固有UI。自由に変更できる。
- `contract.test.ts`: 新しい仕組みと既存ルールの回帰テスト。
- `manifest.json`: 新しい作品のID、名前、版、派生元、ライセンス。

`engine/`, `sdk/`, `runtime/` は共通ホスト。ゲーム拡張のために本体側を変更せずに済むか確かめるため、原則変更しない。

## 守る契約

1. `validate` で合法手を確認、`reduce` は決定的な状態更新。乱数は `resolveAction` / `startAction` でサーバーが確定する。
2. 外部から渡された操作を `parseAction` で検証。クライアント指定の手札・乱数・盤面で上書きしない。
3. `playerView` は他人の手札・山札などを隠す。生のイベント履歴を画面へ送らない。
4. 新しい操作はパーサー・ルール・UI・CPU（必要なら）・テストを一緒に更新する。
5. 新しい作品は元のクレジットとMIT Licenseを維持し、`forkOf` に元作品のIDと固定版を記録する。
6. 外部サービスや追加依存が必要な場合は先に説明する。秘密鍵をファイルに埋め込まない。

## 確認

- `npm test` で契約テストを実行。
- `npm start` で起動し、別ブラウザから同じURLを開いて別席に参加。
- 変更内容、テスト結果、既知の制限を説明し、変更したファイル一式を返す。

このホストはローカル用で、任意コードを安全に実行するクラウドの隔離環境ではありません。
