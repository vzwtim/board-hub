# 島の工房 コード制作キット

Node.js 24以降。依存のインストールなしで動きます。

```sh
npm test
npm start
```

表示される http://127.0.0.1:8788 を開き、ルームを作成。別のブラウザでそのURLを開き「参加」を押します。参加URLに席の秘密トークンは含みません。「おすすめの合法手を実行」で初期配置から進められます。盤面クリックやアクション入力も使えます。

## 派生させる

`AI_REQUEST.md` に希望を書き、フォルダごと外部AIに渡します。ルールは `games/frontier/`、独自の接続は `game.ts`、画面は `ui.html`。JSONの設定項目に限定されません。元の本格UIを移植したものではなく、ルール拡張を試す開発用UIです。

編集後はサーバーを再起動。ソース全体から固定版IDを計算し、対戦保存は `.boardhub/<固定版ID>/` に分離します。ソースが変わると旧版のルームは新サーバーから開けません。旧版対戦を続ける場合は旧ソースの作業ディレクトリで別ポートのホストを起動してください。

## GitHub

ゲームフォルダだけを新しいリポジトリに保存します。BoardHub本体のソース、DB、アカウント情報は含みません。ゲーム用リポジトリの作成後は、GitHubのFork機能で派生できます。`manifest.json` の `forkOf` に派生元とコミットを記録します。

現段階ではGitHubのpushからクラウドへ自動配信する接続とBoardHub本番での公開は未実装です。コードをアップロードすれば本番実行できるとは扱わないでください。

## ローカル実行の範囲

現在のOSユーザー権限でコードを実行します。自分で確認したコードだけを起動してください。ホストは127.0.0.1に限定し、部屋はサーバー側保存、席は秘密トークン、乱数はサーバー確定。参加者が揃うまで操作できません。

本番運用の隔離実行、インターネット向けの認証・濫用対策、ファイルの信頼性検証はこの開発用ホストには含みません。
