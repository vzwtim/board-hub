# 初期作者向け広報・検証

状態: 準備資料。外部投稿・個別送信は未実施。

## 方針

初期は作者の獲得と継続制作の検証を目的にする。作者5人を目標とし、ボードゲーム制作・個人開発・AI制作に関心のある場から小さく始める。公開先と投稿アカウントは実施前に決める。コミュニティの募集ルールと作者の紹介許可を確認する。

広報の順序: 実際に動く制作例→少人数の試作協力募集→改善事例→OSS開発者向け導入資料。新作ゲームの紹介だけで終わらせず、何を変え、どう試し、何を改善したかを示す。

## 初期募集文案

BoardHubで、オリジナルの対戦ゲームを試作してみませんか。

現在は三目・四目などの連結ゲームをベースに、盤面・勝利条件・石の置き方・障害物を変えて、友だちとのオンライン対戦まで試せます。変更案を分岐に保存し、遊んでから採用できます。AI未接続でも設定画面やChatGPTへの依頼文コピーを使えます。

まずは少人数で「つくる→試遊してもらう→改良する」を試し、つまずくところを教えてくれる方を募集する予定です。カードゲーム全般や任意のコード生成にはまだ対応していません。

制作ガイド: https://board-hub.babachan.workers.dev/studio/guide

※募集実施時に、窓口・人数・期間・支援範囲を決めて文面を確定する。未定のまま募集開始しない。

## 紹介素材の構成

1. 元のゲームと「何を変えたいか」を示す。
2. 変更案・差分を見せる。
3. 元の版と変更版を遊ぶ。
4. 招待リンクで第三者が遊ぶ。
5. 感想を受けて再変更し、公開する。

録画は実動作のみ。未実装の感想保存や汎用制作を演出しない。作者名・感想・画面を外部掲載するときは本人の許可を得る。

## 初回観察シート

- 日付 / 作者の同意 / 使用端末
- 作りたいゲームと現在の制作範囲が合うか
- 開始時刻 / 初回変更保存 / 初回試遊 / 第三者対戦完了 / 公開 / 改訂
- 詰まった画面・操作・本人の言葉（掲載同意とは分ける）
- 運営が代わりに行った操作 / 支援時間
- 試遊者の感想 / 作者が採用した変更 / 続けたい理由・続けない理由
- 次に修正する課題 / 担当 / 関連PR

DEV-01完成までは聞き取りで補完するが、アプリ内保存ができるとは案内しない。

## 実施判断

少人数募集: 別ブラウザで招待対戦と改訂まで完了し、保存・所有権・共有の重大不具合がないこと。
拡大募集: 作者が運営のコード修正なしで一周し、サポート時間と離脱原因が把握できていること。
