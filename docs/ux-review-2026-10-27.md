# Player journey review — 2026-10-27

## Observed in the live browser

- My Page: the identity/welcome card, avatar and profile row repeated an action already available in the account icon; game content appeared below them. Removed the card and profile row. The page now contains resumes, favorite games, play history and a secondary creator entry.
- Home: an unsupported friends panel and a year of calendar cells appeared ahead of game discovery. Removed the unfinished friends surface. Kept resumes before the game cards; moved the calendar into a collapsed section under My Page history.
- Favorite collection: a loading interval could show neither games nor an explanation, and first render briefly showed the all-games tab. Initial source now comes from the server URL; collection loading and empty states no longer depend on the unrelated public-project request.
- Game cards: starting CPU play required opening details and choosing a mode. Added direct Play/Resume actions while retaining details, invite and tutorial options.
- Connect Four: added a favorite, opened details, started CPU play, made a move, opened and dismissed rules, returned to Home and confirmed the resume entry existed. Preserving saved games takes priority over starting a fresh game from a card.
- Rules: the duel footer repeated the toolbar rule entry. Removed the duplicate footer controls in duels and community play.
- Learn links for the two duel games went to the mode menu without opening help. They now include a guide flag and open the existing rules dialog.
- Game back button said “game list” but went to Home. Its default destination is now Discover.
- Studio: New Project did nothing visible when empty because templates were already open. The duplicate header action is now shown only when projects exist. Simplified creator copy and changed the login link to open the profile overlay.

## Additional corrections

- The calendar is visual information, not 371 separate keyboard stops.
- My Page collection tabs support arrow, Home and End keys.
- Empty invite input cannot be submitted. Enter submits a nonempty input, and links to another origin are rejected instead of opening a misleading local room.
- Stored play history is validated before display and sorted by latest play date, preserving latest order within a day.

## Verification scope

Type checking, production build, existing engine tests plus malformed/history-order regression tests. Live post-deployment checks cover My Page collections, search and favorite filters, direct resume, rules and profile overlays, and invitation validation. Google-authenticated editing and physical mobile-device testing are not represented as completed by this review.
