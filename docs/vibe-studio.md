# 遊びながら会話で編集する制作画面

`/studio/code/:id` は左にテストプレイ、右に会話を表示する。スマホではタブを切り替えるが、試遊用iframeは維持する。

## 制作の流れ

1. 下書きを読み込むとブラウザー内のテストプレイを自動で起動する。運営のCODE_LOADER接続は不要。
2. 会話で相談・変更を依頼する。直近の会話と現在のソース、チェック時だけ盤面・エラーを送る。
3. AIはJSON形式の差分または相談への返信を返す。差分は既存の編集範囲・ライセンス検証と構文コンパイルを通してから下書きへ保存する。
4. 自動反映がオンなら、新しい下書きで試遊を再起動する。新ルールに旧状態を無理に移植しない。相談だけの場合は対局を維持する。
5. 直前のコード変更を最大10回戻せる。手動編集と新しいゲーム用ファイルの追加も可能。

公開中の版・オンライン対局は下書き変更では更新しない。オンライン試遊と公開には従来の隔離サーバー実行環境が必要で、確認した固定版だけを明示的に公開する。

## 無料モデルとAPI接続

- 運営の共通枠はOpenRouterのみ。モデルIDが`openrouter/free`または`:free`であることをサーバー側で検証し、価格上限を入力・出力とも0、プロバイダーのフォールバックを無効にして送る。有料サービスへの自動切替はしない。
- 公開モデルカタログから入力・出力価格が0、コンテキスト65,536以上の`:free`モデルを最大12件取得する。1時間キャッシュし、取得失敗時も無料ルーターを表示する。モデルの可用性と無料枠の回数には制限がある。
- 共通枠を有効にするには、運営がCloudflareのWorker secret `OPENROUTER_API_KEY` を設定する必要がある。この実装だけでAPIアカウントやキーが作成されるわけではない。キー未設定では未接続と表示する。
- 作者は画面の接続設定でOpenRouter／Groq／Google Gemini／OpenAIを選択し、自分のキーとモデルIDを入力できる。キーによるモデル一覧取得にも対応する。Groq・Geminiの無料枠は契約・モデル・地域で異なるため、無条件の無料と表示しない。有料APIも作者自身の契約で利用する。
- キーはこのタブのReact stateだけに保持する。接続設定はプロジェクト・会話・localStorage・ゲームiframeには保存しない。サーバーはキーを固定されたHTTPSの提供元にのみ転送し、任意のURLやリダイレクトを許可しない。
- 共通枠の上限は作者20回／日、全体200回／日。作者分は`BOARDHUB_AI_DAILY_LIMIT`で1〜200に設定できる。自分のキーは作者100回／日。AIの呼び出しだけが対象で、試遊やコード編集の回数ではない。提供元の上限は別途適用される。

キーの設定例（値はターミナルの対話入力へ。ソースやコマンド引数には書かない）：

```sh
pnpm exec wrangler secret put OPENROUTER_API_KEY
```

## 端末内のテストプレイ

作者が所有する下書きをサーバーで構文検査・CommonJSへ変換する。ゲームコード自体はサーバーで実行しない。`sandbox="allow-scripts"`のopaque iframe内から使い捨てのWorkerを作り、ゲームのルールをそこで実行する。iframeにはAPIキーやアカウントCookieを渡さない。CSPで外部通信・別フレーム・フォーム送信を制限し、Workerの応答が4秒を超える場合は終了する。ブラウザーのUIスクリプトそのものに無限ループを書いた場合など、端末内の資源使用を完全に保証するサーバー隔離ではない。任意コードの本番公開には利用しない。

ローカルの対局は手番に応じて操作する席を自動で切り替える。友だちの招待やオンライン対戦ではなく、作者が複数席を操作するテストプレイ。状態とルームはiframeの起動中だけ保持し、公開版には書き戻さない。

## 検証と制限

- `pnpm test`：モデル選択、無料枠制限、接続先固定、キー非露出、相談のみの返信、会話上限、CSPとheader保持を検証。
- `pnpm studio:smoke`：実際の島の工房ソースをコンパイルし、ブラウザーWorkerの本物のペイロードで開始・おすすめ手・revision・席切替・公開ビューを検証。
- `pnpm code:smoke`：Cloudflare互換のWorker内でローカル用コンパイルと既存のオンライン隔離実行を検証。
- ブラウザーのUIテストは`node scripts/smoke-local-playtest.mjs --fixture`、`node scripts/vibe-ui-fixture.mjs`で作る使い捨てfixtureを使用する。AI応答と保存はモックで、テストプレイは実ゲームコード。会話によるタイトル変更→自動反映→取り消し→合法手の実行、および390px幅での表示切替を確認する。生成した`public/vibe-fixture.*`はテスト後に削除し、配布しない。
- 実際の提供元キーを使うAI生成は、この作業では未検証。運営キーを設定したとは扱わない。通常アプリの作者認証はHTTPS本番で別途確認する。ローカルHTTPプレビューの作者Cookie制約を回避するため、製品の認証を緩める変更は行わない。
